# Página web: capturas

Capturas de la página web de uso interno de Las 3 Delicias.

> **Aviso:** por solicitud del propietario la página **no se publica ni se enlaza**, porque contiene datos del negocio que no desea compartir. Estas capturas son de una **versión anterior**, previa a que el propietario modificara los datos, y no reflejan el estado actual. Los registros que se ven (por ejemplo, el stock en cero y los movimientos de prueba del 11 de noviembre) son de esa etapa de prueba y **no** corresponden al seed de `db/`.
