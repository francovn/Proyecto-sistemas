# Sistema de gestión de inventario - Las 3 Delicias

Proyecto desarrollado para la asignatura ICN292, enfocado en el diseño de un Sistema de Información para la Gestión de la PYME Las 3 Delicias.

## PYME y problemática

Las 3 Delicias es una pequeña empresa ubicada en Quilicura, dedicada a la elaboración y venta de pasteles y masas.

Actualmente, el control de materias primas se realiza principalmente mediante revisión visual y experiencia de los trabajadores, sin contar con un registro centralizado de inventario.

Esto puede provocar quiebres de stock, compras imprevistas, dificultades para coordinar las compras y pérdidas de productos o materias primas.

La solución propuesta busca centralizar el registro de las entradas, salidas y existencias de materias primas, permitiendo consultar el stock disponible y apoyar las decisiones de reposición.

## Relación con la Entrega 2

En la Entrega 2 se desarrollará un prototipo funcional ejecutable en localhost. Este permitirá registrar y consultar información del inventario, manteniendo actualizadas las existencias y apoyando la planificación de compras.

Inicialmente se considera utilizar Python, Streamlit y SQLite para el desarrollo del prototipo.
